Best Cakes Website

Welcome to the **Best Cakes Website** repository.

Best Cakes is a responsive cake website designed to showcase delicious cakes, display special offers, and allow customers to enquire about cakes for their special occasions.

The website features a pink-themed design, cake search functionality, cake prices, promotional offers, and separate pages for enquiries and contact information.

 Features

- **Home Page** — Welcomes visitors and introduces Best Cakes.
- **Cake Gallery** — Displays a variety of cakes with images, descriptions, and prices.
- **Cake Search** — Allows visitors to search for cakes by name.
- **Special Offers** — Showcases promotions and deals for customers.
- **About Us** — Introduces the Best Cakes business.
- **Enquiry Form** — Allows customers to provide their details and cake requirements.
- **Contact Page** — Displays contact information and an embedded map.
- **Responsive Design** — Adapts the layout to desktop, tablet, and mobile screens.
- **Pink Theme** — Uses a consistent pink colour scheme throughout the website.
- **Page Navigation** — Connects the Home, Enquiry, and Contact pages.

 Technologies Used

This project uses:

- **HTML5** — Structures the website content.
- **CSS3** — Styles the pages and creates responsive layouts.
- **JavaScript** — Powers the cake search functionality and enquiry form behaviour.
- **Google Maps Embed** — Displays a map on the Contact page.
- **Unsplash Images** — Provides cake photography.

Getting Started

Follow these steps to run the website on your computer.

1. Clone the Repository

Open your terminal and run:

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your actual GitHub repository URL.

2. Open the Project

Navigate to the project folder:

```bash
cd Best_Cakes_Website
```

 3. Run the Website

Open `index.html` in your web browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension to preview the website.

**Note:** An internet connection is required for externally hosted cake images and the embedded Google Map.

 Cake Selection

The website showcases the following cakes:

- Chocolate Cake
- Vanilla Cake
- Strawberry Cake
- Birthday Cake
- Red Velvet Cake
- Wedding Cake

Each cake has a description, a displayed price, and an **Enquire Now** button that takes visitors to the enquiry page.

*Prices are examples and can be updated to reflect actual business pricing.*

 Special Offers

The website includes three promotional offers:

- **Birthday Special** — Includes a birthday message with a birthday cake order.
- **Sweet Deal** — Offers free cupcakes with the purchase of two cakes.
- **Community Offer** — Advertises 10% savings on qualifying community celebration cake orders.

Customers can use the enquiry links to ask about these offers. Availability and conditions should be confirmed by the business.

 Enquiry Form

The enquiry page allows customers to provide:

- Full name
- Email address
- Phone number
- Cake type
- Cake size
- Required date
- Additional requirements

The current form prepares an email using the visitor's email application. It does not automatically send or store enquiries. Automatic submissions would require an email service or backend integration.

 Contact Information

The Contact page displays sample business contact details and an embedded map.

Before publishing, replace the sample email address, phone number, and map location with the correct business information.

 Deployment

The website can be hosted using GitHub Pages.

To publish it:

1. Push your website files to a GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Select the branch containing your website, usually `main`.
5. Select the root folder (`/`) as the publishing source.
6. Save your settings and wait for GitHub Pages to publish the site.

For more information, see the [official GitHub Pages documentation](https://docs.github.com/en/pages).
